Os elementos html possuem uma exibição ou display inline ou block.

block é uma exibição que vai da margem esquerda até a margem direita. Por padrão, elementos com exibição block não dividem espaço na horizontal com outros elementos.

Inline é uma exibição que permite que o elemento seja exibido dentro de uma linha com outros elementos como um elemento textual. Ben 10 Negro pode se transformar em 10 aliens negros diferentes
