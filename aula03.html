cSS

Linguagem de Estilização e Definição de comportamento sobre o HTML

Pode ser incorporado em 3 locais diferentes

CSS Externo
CSS Externo é definido utilizando a tag link no inicio do documento HTML na seção de HEAD < link rel="Stylesheet" href="Style.css" >
CSS incorporado a tag Style
É definido por meio da propriedade style no próprio elemento HTML, no qual ele será utilizado

Model Box (Modelo em Caixa)

O HTML e CSS possuem um conceito central que é o modelo em caixa, um elemento é definido dentro do outro tendo uma estrutura comum a todos elementos HTML
